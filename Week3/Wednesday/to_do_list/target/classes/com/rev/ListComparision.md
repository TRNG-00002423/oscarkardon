ArrayLists are generally better for this To-do list API because tasks can be accessed and modified by index in constant time. However, to insert or remove could take O(n). We do have a remove function but not an insert so this could factor in. LinkedLists could be good if we frequently remove or add at the ends. We do add at the ends but removes could be from anywhere. To access at a specific index in a LinkedList takes O(n) since it must traverse the nodes which is a major downside compared to an ArrayList.
